# Fonts for the link-preview image

Static instances used by `apps/api/src/og.ts` to render `/og.png` with resvg.

- Bricolage Grotesque ExtraBold and Medium — https://github.com/ateliertriay/bricolage
- JetBrains Mono Bold and Medium — https://github.com/JetBrains/JetBrainsMono
